# Customer Loyalty & Purchase Behavior Analysis – Looker Studio

## Project Overview

This project analyzes **customer loyalty, purchase behavior, and revenue performance** using Looker Studio dashboards and business insight presentation.

The objective is to identify:

* High-value customer segments
* Effectiveness of the loyalty program
* Geographic revenue concentration
* Purchase intent and channel performance

## Key Business Insights

* Transaction volume increased, but **revenue per customer remained stagnant**
* Customers aged **18–24 generate the highest average purchase value**
* The current **loyalty program shows limited impact on repeat purchase**
* **Omnichannel customers deliver the highest overall value**

## Strategic Recommendations

* Redesign loyalty rewards toward **value-based incentives**
* Target **young high-value customers (18–24)**
* Activate **planned buyers** with bundles and scheduled promotions
* Strengthen **online–offline omnichannel integration**
